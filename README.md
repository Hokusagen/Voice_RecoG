# VoiceTyper

Голосовой ввод для Windows: зажали клавишу, продиктовали, отпустили — текст
появился в активном окне уже причёсанным.

Речь распознаёт [faster-whisper](https://github.com/SYSTRAN/faster-whisper)
локально на видеокарте, черновик вычищает локальная модель через
[Ollama](https://ollama.com). Ничего никуда не отправляется.

## Как это выглядит

Вместо системных уведомлений — стеклянная плашка внизу экрана. Она снимает и
размывает то, что под ней, поэтому выглядит как настоящее матовое стекло, а не
как серый прямоугольник.

Непрерывная анимация во всём интерфейсе ровно одна: свечение, бегущее по кромке.
**Цвет** говорит о стадии, **скорость и яркость** — об активности.

| Состояние | Цвет кромки | Слева |
|---|---|---|
| Загружаю модель | синий, медленно | дышащая точка |
| Слушаю | красный; яркость идёт за громкостью голоса | тонкая осциллограмма и таймер |
| Распознаю | синий | дышащая точка |
| Причёсываю | фиолетовый | дышащая точка |
| Готово | зелёный, ровный ободок | галочка прорисовывается штрихом |
| Ошибка | красный, ровный ободок | крестик |

Никаких спиннеров, бегущих бликов и подпрыгивающих точек: плашка живёт на
периферии зрения и не должна тянуть взгляд на себя.

Она прозрачна для мыши и не забирает фокус, так что Ctrl+V попадает туда, куда
вы диктуете. Иконка в трее — тот же язык: форма микрофона не меняется, меняется
цвет, а работу показывает медленное дыхание прозрачностью.

Посмотреть оформление, ничего не диктуя:

```bash
venv\Scripts\python.exe src\demo.py
```

### Про стекло

Плашка снимает то, что под ней, и обсчитывает кромку как настоящую линзу
([src/ui/liquid.py](src/ui/liquid.py)): у края выборка фона смещается вдоль
нормали к контуру, каналы расходятся, сверху ложится блик, под ним — тень от
толщины. Середина стекла толстая и размывает сильнее, кромка тонкая и почти не
рассеивает, зато преломляет.

Стекло живое: фоновый поток снимает экран и пересобирает размытие десятки раз
в секунду ([src/ui/live.py](src/ui/live.py)), поэтому прокрутка и видео под
плашкой видны сквозь неё. Чтобы не снимать саму себя, плашка исключена из
захвата экрана — из-за этого её не видно в OBS, Zoom и записях экрана. Ключ
`ui.liquid_live: false` возвращает прежний режим с одним снимком при появлении
(и видимость в записях).

Материал выбирается по замеренной светимости фона: над светлым документом
плашка становится светлым стеклом с тёмным текстом, над тёмным окном — тёмным.
Если фон под плашкой меняется прямо во время показа, стекло плавно перетекает
из одного материала в другой.

### Про шрифт

По умолчанию — **Segoe UI**, и это не лень. Он вручную отхинтован под мелкие
кегли Windows, поэтому на 12–14 пикселях штрихи попадают ровно в пиксельную
сетку. Inter, Onest, Golos Text и Manrope инструкций хинтинга не несут и на тех
же кеглях расползаются — проверено рендером всех четырёх от 11 до 15 пикселей.

Все четыре всё равно лежат в [assets/fonts](assets/fonts) и включаются ключом
`ui.font` в конфиге: на экране с крупным масштабом они могут зайти лучше.

## Установка

Нужен Python 3.11+ и микрофон.

```bash
python -m venv venv && venv\Scripts\activate && pip install -r requirements.txt
```

Для работы на видеокарте NVIDIA больше ничего не требуется — CUDA-библиотеки
приезжают пакетами `nvidia-*` из `requirements.txt`. Без видеокарты приложение
само переключится на процессор.

Постобработку текста включает Ollama:

```bash
ollama pull qwen2.5:3b
```

Без неё всё продолжит работать — просто вставится сырой текст Whisper.

## Запуск

```bash
venv\Scripts\python.exe src\main.py
```

Приложение живёт в трее. Первый запуск скачивает модель распознавания
(`large-v3-turbo`, около 1.6 ГБ) — плашка честно об этом предупредит.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `F8` | Диктовать: распознать и причесать моделью (стиль выбирается в трее) |
| `Shift+F8` | То же, но в другом стиле: сухом, если по `F8` бережный, и наоборот |
| `Ctrl+F8` | Быстро: вставить сырой текст, не дожидаясь Ollama |
| `Esc` | Отменить активную запись |

Стилей правки два. Бережный убирает слова-паразиты и расставляет знаки, но
оставляет каждое осмысленное слово на месте. Сухой снимает всё разговорное и
оставляет только суть — так удобно диктовать задания и промпты. Какой из них
висит на `F8`, выбирается в меню трея «Правка по F8»; второй всегда на
`Shift+F8`.

В меню трея переключается режим клавиши: удерживать (по умолчанию) или
нажать один раз для старта и второй для остановки. Меню открывается и левым,
и правым кликом по иконке.

### Облако

Локальные модели, которые влезают в 4 ГБ, чистят мусор, но сухой стиль им не
даётся. Для него есть облако: любой OpenAI-совместимый сервер, по умолчанию
Groq — бесплатный тариф без карты, тысяча правок и восемь часов аудио в сутки,
на данных не обучают. Ключ с console.groq.com вставляется в `cloud.api_key`,
после чего в трее в меню «Редактор» появляется выбор: локально или в облаке.
Пока правит облако, Ollama не занимает видеопамять; если облако не ответило,
правка уходит в Ollama, а без неё вставляется сырой текст с предупреждением.
Бесплатный тариф Groq ограничен восемью тысячами токенов в минуту, это
пять-шесть диктовок подряд, и тысячей правок в сутки. Остатки видны в меню
трея под строкой состояния и пишутся в журнал. Перед каждой правкой
приложение сверяется с ними: если минутного лимита на фразу не хватает и
сброс через пару секунд — ждёт, если дальше или кончились суточные запросы —
сразу отдаёт правку Ollama. За полсотни оставшихся правок плашка предупредит,
а когда лимит восстановится — сообщит «Лимит по токенам в минуту восстановлен».

Всё, что диктуется с включённым облаком, уходит на его сервер. Если для
рабочих диктовок это неприемлемо, оставьте редактор локальным.

### Отдать видеокарту

Whisper и Ollama вместе занимают около 3.5 ГБ видеопамяти. Когда она нужна
другой задаче — обучению модели, рендеру, — пункт трея «Отдать видеокарту»
выгружает редактор и переселяет Whisper на процессор. Диктовка продолжает
работать. С ключом облака распознавание тоже уходит туда и занимает секунду;
без ключа — на процессор, где turbo распознаёт в реальном времени. Правка в
этом режиме есть только облачная. Снятие галочки возвращает всё на
видеокарту за десяток секунд. Состояние запоминается между запусками.

## Настройки

Всё правится в `%APPDATA%\VoiceTyper\config.json` — файл создаётся и
открывается пунктом «Открыть настройки» в меню трея. Изменения подхватываются
при следующем запуске.

Сам по себе файл не появляется намеренно: записанные при первом запуске
умолчания потом перекрывали бы новые, и обновление приложения не меняло бы
ничего.

Что чаще всего хочется поменять:

| Ключ | Смысл |
|---|---|
| `hotkeys.record` | Основная клавиша |
| `whisper.model` | `large-v3-turbo`, `medium`, `small` — компромисс точность / память |
| `whisper.compute_type` | `int8_float16` экономит вдвое видеопамяти против `float16` |
| `whisper.initial_prompt` | Термины вашей предметной области — Whisper распознает их точнее |
| `llm.enabled` | Выключить постобработку целиком |
| `llm.journal` | Журнал диктовок в `dictations.jsonl`: сырой текст, правка модели, тайминги |
| `llm.system_prompt` | Правила бережной правки |
| `llm.dry_prompt` | Правила сухой правки |
| `llm.style` | Стиль по основной клавише: `careful` или `dry` |
| `llm.backend` | Где править: `local` (Ollama) или `cloud` (переключается в трее) |
| `cloud.api_key` | Ключ облака; пустой — облако выключено |
| `cloud.url`, `cloud.model` | Сервер и модель редактора: по умолчанию Groq и `qwen/qwen3.8-27b` |
| `whisper.cloud_when_released` | Распознавать в облаке, пока видеокарта отдана |
| `whisper.cpu_model` | Модель на время «Отдать видеокарту»: `large-v3-turbo` (точно, ~15 с на фразу) или `small` (~4 с, хуже термины) |
| `release_gpu` | Видеокарта отдана: Whisper на CPU, Ollama выгружена (переключается в трее) |
| `audio.preroll_ms` | Сколько звука «до нажатия» подмешивать, чтобы не срезалось начало |
| `audio.idle_close_s` | Через сколько простоя отпускать микрофон |
| `ui.hud_position` | `bottom`, `top`, `bottom-right`, … |
| `ui.liquid_live` | Живое стекло; `false` — один снимок при появлении, зато плашку видно в записях экрана |
| `ui.font` | `auto`, `Segoe UI`, `Inter`, `Onest`, `Golos Text`, `Manrope` |
| `ui.success_hold_ms` | Базовое время показа результата; ко времени чтения текста прибавляется 30 мс на знак |

## Сборка в .exe

```bash
python build.py
```

Скрипт закрывает работающее приложение — иначе PyInstaller не перезапишет
занятый `.exe`, — собирает и поднимает его обратно. `--yes` пропускает вопрос,
`--no-run` оставляет приложение закрытым.

Готовое приложение — в `dist\VoiceTyper\`; под капотом всё та же команда
`venv\Scripts\pyinstaller.exe VoiceTyper.spec`.

Номер версии — `APP_VERSION` в `src/config.py`, он же виден в подсказке трея и
в каждой записи журнала. Что менялось — в [CHANGELOG.md](CHANGELOG.md).

## Как устроено

```
src/
  main.py          точка входа: единственный экземпляр, QApplication, трей
  demo.py          прогон всех состояний без микрофона и моделей
  config.py        настройки и config.json
  controller.py    связывает клавиши, запись, конвейер и интерфейс
  core/
    cuda_paths.py  регистрация CUDA-DLL до импорта ctranslate2
    audio.py       микрофон, кольцевой пре-ролл, уровень сигнала
    stt.py         faster-whisper с откатом на процессор
    llm.py         Ollama: прогрев, keep_alive, разбор ответа
    paster.py      вставка с сохранением буфера обмена
    hotkeys.py     низкоуровневый хук клавиатуры
    pipeline.py    фоновая очередь: звук -> текст -> правка -> вставка
    sounds.py      синтез сигналов в памяти
    history.py     последние диктовки
    autostart.py   автозапуск через реестр
  ui/
    hud.py         экранная плашка
    liquid.py      стекло: преломление кромки, блик, дисперсия
    glass.py       снятие фона под плашкой
    indicators.py  свечение по контуру и значки состояний
    shadow.py      размытая тень
    tray.py        иконка и меню в трее
    theme.py       материалы, палитра, метрики, шрифты
assets/fonts/      Inter, Onest, Golos Text, Manrope
```

Обработка идёт в отдельном потоке с очередью: пока распознаётся одна фраза,
можно диктовать следующую, а пауза и выход срабатывают мгновенно.
