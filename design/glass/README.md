# Лаборатория стекла плашки

Живые WebGL-концепты экранной плашки VoiceTyper. Здесь подбираем внешний вид до того, как
переносить его в приложение: в `src/` попадёт только выбранный вариант.

Страница «Шесть стёкол» опубликована приватно: сверху второй круг — три тела Дарви с
переключателями реакции и темперамента, ниже первый круг:
https://claude.ai/artifact/7k7nAm8J21revgmmcgvNmJ

- `NEXT.md` — план второго круга: три варианта по итогам отзывов.
- `../DARVI.md` — Дарви, персонаж плашки: характер, эмоции и классификатор; второй круг выбирает
  ему тело.
- `RESEARCH.md` — выжимка исследования: оптика Apple в числах, слияние капель, пружины, голос,
  текст, что умеет Windows.
- `HARNESS.md` — как написать концепт: API основы, стекло, проверка снимками.
- `harness.js`, `stage.css` — основа: сцена за стеклом, состояния, голос, пружины, GLSL и стекло
  по замерам Apple; у каждого круга свои часы, голос и тексты.
- `kit.js` — общие куски второго круга: цвет итогов из «Сияния», формы и морф Material 3,
  линза от гладкой формы, свечение «из-под пальца»; `probe2.js` — минимальный пример.
- `lens.js`, `mercury.js`, `aura.js`, `membrane.js`, `island.js`, `fog.js` — концепты первого
  круга; `probe.js` — минимальный пример.
- `lumen.js`, `quicksilver.js`, `grain.js` — второй круг: «Линза·Свет», «Ртуть», «Зерно».
- `index.html`, `concepts.js` и `concepts2.js` — страница и тексты обоих кругов.
- `solo.html` — один концепт: `solo.html#lens/done/photo/0` (стадия, фон, скорость прокрутки;
  `/flat` — без линзы, как в композиторе Windows; `//t=2.6` — замороженное время для снимка).
- `voice/` — голос в «Слушаю» (6 октября 2026): из семи стоп-кадров выбраны «Капли» и «Шёлк»
  на прозрачном стекле, оба живьём — с имитацией речи или со своим микрофоном
  (`http://127.0.0.1:8000/voice/`). «Шёлк» перенесён в приложение (`src/ui/lens_shader.py`)
  с теми же числами. В консоли страницы: `VoiceSketches.film()` — кадры в замороженном
  времени, `trace()` — дрожь на частотах слогов, `bench()` — стоимость кадра.
- `shoot.py` — снимки в безголовом Edge, в том числе ряды моментов (`--series`); `trace.py` —
  числа движения по кадрам; `contrast.py` — контраст подписи по худшему пикселю;
  `sheet.py` — склейка снимков разных концептов в лист (Python из venv).
- `windows/` — нативные опыты на системном композиторе (pywinrt + ctypes). `comp_blur.py` —
  мост для размытия живого фона без «Эффектов прозрачности»; `glass_proto.py` — прототип
  плашки; `goo_probe.py` — жидкое слияние в DWM; `fx_accept2.py` — какие эффекты принимает
  композитор; `wda_matrix.py` — какие окна можно исключить из захвата; `hybrid_probe.py` —
  стекло Линзы без видимого отставания: живая середина композитора, кромка шейдером D3D11 по
  захвату (`--look` — снимок, `--measure` — замер запаздывания). Нужны пакеты `winrt-*`
  3.2.1, в requirements их нет.

## Как смотреть

Открыть `index.html` в Edge или Chrome. Если браузер не грузит скрипты с диска — поднять сервер
в этой папке и открыть http://127.0.0.1:8000/:

```bash
python -m http.server 8000 --bind 127.0.0.1
```

Снимки и сырой отчёт исследования (`shots/`, `research.json`) в git не идут.
