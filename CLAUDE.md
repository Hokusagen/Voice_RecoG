# VoiceTyper — контекст для Claude Code

Голосовой ввод: зажал клавишу, продиктовал, отпустил — текст вставился в
активное окно. Windows и macOS, Python 3.12, PySide6. Подробности в README.md,
история версий в CHANGELOG.md, версия в `src/config.py` (`APP_VERSION`).

## Как работаем

- Код, комментарии, коммиты и ответы — по-русски. Комментарии объясняют,
  почему сделано так, а не что делает строка.
- Коммит-сообщения: первая строка — суть, дальше короткий список пунктов.
  Каждая законченная задача — отдельный коммит; пушить только по просьбе.
- Интерфейс смотрим живьём (`python src/demo.py` гоняет плашку по состояниям),
  а не по рендерам. В анимации минимализм: одно движение в кадре.
- Отчёты и эксперименты не коммитим, только код и документы.

## Запуск из исходников

```
python -m venv venv
source venv/bin/activate            # Windows: venv\Scripts\activate
pip install -r requirements.txt     # или requirements-lite.txt: без локальных моделей
python src/main.py
```

Лог: `voicetyper.log` в каталоге данных — `%APPDATA%\VoiceTyper` на Windows,
`~/Library/Application Support/VoiceTyper` на macOS. Там же `config.json`,
`dictations.jsonl` (журнал диктовок) и `crash.log`.

Сборка: `python build.py --yes` (полная), `--lite` (только облако).
Релиз: тег `vA.B` на коммите с той же версией запускает GitHub Actions.

## Версии

Номер вида A.B (`APP_VERSION` в `src/config.py`) меняется только при выпуске —
когда Антон решает отдать сборку, — а не с коммитом и не с задачей. Между
выпусками изменения копятся в CHANGELOG под «A.B — в работе», где A.B — номер
следующего выпуска.

B + 1 — выпуск, в котором человек заметит разницу:
- новая возможность: клавиша, режим, пункт трея, умение Дарви;
- заметно другое поведение распознавания, правки, вставки, плашки, звука или
  значений по умолчанию;
- новый источник распознавания или правки: облако, модель, сервер;
- исправления, без которых жилось плохо (терялся текст, падало, не
  вставлялось), — тоже выпуск и тоже B + 1: третьего числа нет.

A + 1, B = 0 — выпуск, после которого нельзя просто продолжить по-старому:
- старые `config.json`, журнал или каталог данных не читаются без переноса
  или сброса;
- основной сценарий меняется так, что ломаются привычки: другая схема клавиш,
  диктовка перестаёт быть главным режимом;
- снимается поддержка платформы или поднимаются требования к системе;
- 0 → 1 — первый выпуск, который не стыдно отдать другим: диктовка на Windows
  стабильна, известных ошибок с потерей текста нет, форматы настроек и журнала
  устоялись, сборка ставится без возни. До этого A = 0.

Номер не меняют: рефакторинг, тесты, CI, документы, лаборатория `design/`,
замеры и внутренние инструменты, всё, чего пользователь не видит. Две задачи
за день — не два номера. B — целое: после 0.9 идёт 0.10, к 1.0 переходят по
правилу для A, а не по счёту. Выпуск — одним коммитом: `APP_VERSION`,
заголовок с датой в CHANGELOG и тег `vA.B`. Хвост вида `+182.ef63e54` — не
версия, а сборка: git дописывает его сам с каждым коммитом, чтобы по журналу
было видно, какой код писал запись. До правила номер поднимали по задачам:
0.1–0.8.1 трёхчастные, выпущен из них только `v0.5.0`.

## Состояние macOS-порта (сентябрь 2026)

Портировано вслепую с Windows и на живом Mac ещё не запускалось. CI на
macOS-раннере проверяет только импорт модулей. Что именно платформенное:

- `core/hotkeys.py` — бэкенд pynput (на Windows — keyboard).
- `core/paster.py` — pbcopy/pbpaste и Cmd+V через pynput.
- `core/sounds.py` — afplay; `core/autostart.py` — LaunchAgent;
  `main.py` — файл-замок вместо мьютекса; `config.app_data_dir()`.
- `ui/live.py` живое стекло — только Windows; на Mac работает статичный
  снимок из `ui/glass.py`, ему нужно разрешение «Запись экрана».

Порядок отладки на Mac: запуск из исходников → разрешения (микрофон,
Универсальный доступ, Запись экрана; выдаются приложению-родителю: Терминалу
или VS Code) → горячая клавиша (F8 на Mac занята плеером, возможно, нужен
другой дефолт) → вставка в TextEdit и VS Code → `.app` из релиза (не подписан,
снимать карантин: `xattr -dr com.apple.quarantine VoiceTyper.app`) →
автозапуск и звуки. Всё, что заработает или сломается, записывать в README
(раздел «Установка») и CHANGELOG.

## Облако

`cloud.api_key` в config.json — ключ Groq пользователя, в код и в вывод не
попадает. Лимиты бесплатного тарифа: 8k токенов в минуту, 1000 правок в сутки.

## Дизайн плашки

Новый вид плашки подбирается в `design/glass`: живые WebGL-концепты на стекле,
откалиброванном по замерам Apple Liquid Glass (обзор — README там). Первый круг
из шести концептов пройден 26 сентября 2026, план второго — `design/glass/NEXT.md`.
В `src/ui` переносится только выбранный вариант. Настоящая линза без задержки на
Windows возможна только внутри DWM — см. `design/glass/RESEARCH.md`. Голос в
«Слушаю» — «Шёлк», выбран 6 октября 2026 из стоп-кадров `design/glass/voice`;
числа там и в `src/ui` должны совпадать.

Плашка — персонаж Дарви (Darvi): темперамент, эмоции по тексту и по ходу работы,
классификатор и правила, чтобы не надоесть, — `design/DARVI.md`.
